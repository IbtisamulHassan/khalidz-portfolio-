# Ibtisamul Hassan Khalid — Portfolio
Single-page portfolio (index.html + assets). Publish free on GitHub Pages:
1. Create a repo, upload all files (keep the `assets/` folder and `.nojekyll`).
2. Repo Settings → Pages → Deploy from branch `main` / root.
3. Site goes live at https://YOUR-USERNAME.github.io/YOUR-REPO/
Then replace the SITE_URL placeholders in index.html (canonical, og:url, og:image, twitter:image).
